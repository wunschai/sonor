# Sonor — 迷霧太空即時戰略遊戲 Prototype

## 背景 (Background)

打造一款類 Homeworld 風格的 2D 俯視太空即時戰略遊戲，全圖被迷霧覆蓋，玩家只能透過單位視野和聲納系統來感知環境。核心特色是聲納偵測機制——主動脈衝掃描與被動音量偵測——搭配採礦、建造、戰鬥三大系統。

技術選型：Python + Pygame、單人對 AI、Prototype 規模。

## 粗略目標 (High-level Goals)

- 實作全圖迷霧戰爭，每個單位有自己的可見圓
- 實作主動聲納（脈衝擴散、強度衰減、物體輪廓閃光）
- 實作被動聲納（依音量大小顯示模糊光點）
- 三大核心系統：採礦、建造、戰鬥
- 簡單敵方 AI 狀態機
- 小地圖（聲納光點 + 礦場標記）+ 基本 HUD

## 技術規格

### 平台
- Python 3.11+
- Pygame 2.x
- 無額外物理引擎（純手寫移動邏輯）
- 架構風格：輕量模組化（ECS 概念，非完整框架）

### 視角
- 2D 俯視（top-down）
- 可拖動視角，支援鍵盤 WASD 或滑鼠邊緣捲動

## 迷霧系統

地圖與迷霧同尺寸的 Pygame Surface，三種狀態：

| 狀態 | 說明 | 顯示 |
|------|------|------|
| DARK | 從未見過 | 純黑，完全不透明 |
| SHROUD | 曾見過，目前無視野 | 半透明黑（地形可見，無動態單位） |
| VISIBLE | 當前有單位視野涵蓋 | 完整顯示 |

每 frame 流程：
1. 全圖重置為 SHROUD（保留已見區域記錄）
2. 遍歷所有玩家單位，以 `vision_radius` 畫圓 → 設為 VISIBLE
3. 繪製時：DARK 蓋全黑，SHROUD 疊半透明黑

## 聲納系統

### 強度三級

| 強度 | 光點大小 | 清晰度 |
|------|--------|-------|
| 1 | 小 | 清晰 |
| 2 | 中 | 輕微模糊 |
| 3 | 大 | 明顯模糊 |

### 主動聲納（Active Pulse）

- 觸發：玩家按 `S` 鍵，由選取艦艇發射
- 脈衝強度 = 船的大小級別（S/M/L 對應 1/2/3 級）
- 每經過固定距離（例如 200px）衰減一級，降至 0 消失
- 小型船脈衝只打一級，衰減快；大型船可打三級，覆蓋遠
- 波環觸碰到物件時：
  - 主視圖：接觸點顯示**輪廓閃光**，隨時間從清晰逐漸模糊至消失（~1.5 秒）
  - 光點大小 = `min(物體大小, 當前脈衝剩餘強度)`
  - 小地圖：亮白色光點同步 fade out
- 物體越大，輪廓和光點越大

### 被動聲納（Passive Detection）

- 所有玩家單位持續偵測 `passive_radius` 內的移動物件
- 音量計算：`音量 = 移動速度 × 船的大小`，映射到強度 1/2/3 級
- 偵測到後：小地圖顯示**模糊橘色光點**（位置有 ±N 像素誤差）
- 光點大小對應音量強度，隨時間模糊消退
- **不觸發主視圖輪廓**，只在小地圖顯示

## 單位與建物

### 戰鬥艦艇（三種尺寸）

基礎值設定（具體數字由 spec 定義）：

| 屬性 | 小 (S) | 中 (M) | 大 (L) |
|------|-------|-------|-------|
| 建造時間 | 1× | 3× | 7× |
| HP | 1× | 3× | 7× |
| 攻擊力 | 1× | 2× | 4× |
| 攻擊速度 | 3× | 2× | 1× |
| 聲納發射強度 | 1 | 2 | 3 |

### 特殊單位

| 單位 | 大小 | 說明 |
|------|------|------|
| 母艦 | L | 初始存在，不可建造，被摧毀即輸 |
| 採礦船 | S | 採礦、運輸，自動往返礦場與母艦 |
| 建造船 | S | 前往指定位置建造建物 |

### 建物

| 建物 | 說明 |
|------|------|
| 採礦站 | 提升附近採礦效率 |
| 砲塔 | 自動攻擊射程內敵人，戰力 = 中型船 |

## 採礦系統

- 小行星分 S / M / L 三種大小，礦物量 Prototype 階段設為無限
- 採礦船靠近並 attach，每秒抽取固定量礦物
- 採礦船裝滿後自動返回母艦卸貨
- 礦場被視野或聲納觸及後，在地圖上**永久標示**位置
- 小地圖顯示綠色方塊，主視圖標示礦場名稱及剩餘量（Prototype 顯示「∞」）

## 建造系統

- 玩家選取建造船 → 指定目標位置與建物種類 → 扣除礦物資源 → 建造船前往 → 進度條 → 完成
- 建造中的建物有血量，可被攻擊摧毀（進度歸零、資源不退還）

## 戰鬥系統

- 進入 `attack_range` 自動開火（Prototype：自動瞄準最近敵人）
- 傷害直接扣 HP，歸零後單位消除
- 勝負條件：敵方母艦被摧毀即輸

## 敵方 AI（狀態機）

```
IDLE → 採礦 → 建造 → 擴張
                 ↓
             偵測到玩家 → 攻擊 → 返回
```

- Prototype 階段：AI 可見全圖（作弊模式），優先採礦 → 建砲塔 → 建戰艦 → 派兵攻擊
- 後期可改為 AI 也受迷霧限制

## UI / HUD

### 主視圖
- 左上：礦物資源量、收入速率
- 下方（選取單位後）：HP 條、艦種名稱、可用指令按鈕
- 聲納脈衝波形疊加在地圖上（半透明環，碰到物體後顯示輪廓閃光）

### 小地圖（右下角）
- 白點：玩家單位
- 紅點：已知敵方單位
- 亮白光點：主動聲納 hit（fade out）
- 模糊橘光點：被動聲納偵測（fade out）
- 綠色方塊：已知礦場（永久標示）

### 操作
| 輸入 | 動作 |
|------|------|
| 左鍵 | 選取單位 |
| 左鍵拖拉 | 框選多單位 |
| 右鍵 | 移動 / 攻擊目標 |
| `S` | 選取艦艇發射主動聲納 |
| `WASD` | 捲動視角 |
| 點擊小地圖 | 跳轉視角 |

## 可能的方向 (Potential Directions)

### 方案 A — 模組化 ECS 風格（選定）
- 每個遊戲物件掛上 Position、Vision、Sonar、Health 等 component
- 系統（System）負責更新邏輯
- **優點**：結構清楚、好測試、易擴展
- **缺點**：比單檔多一點前期設計成本

### 方案 B — 單檔快速 prototype
- **優點**：起步最快
- **缺點**：超過 500 行後維護困難，聲納 + 迷霧 + AI 邏輯容易交織爛掉

### 方案 C — 加入 pymunk 物理引擎
- **優點**：移動手感有太空漂移感
- **缺點**：聲納/迷霧需配合物理框架，複雜度大幅提高
